`npx passport-mrz-ocr-assets <dir>` copies the worker, the wasm cores and the model into a
directory of your site, together with the tesseract.js and tesseract.js-core license files.
The playground's build does the same into `playground/public/ocr/` (not committed; generated at
build time).

### MRZ-specific OCR models: not used

MRZ / OCR-B trained Tesseract models exist (for example `tessdata_ocrb` and `tesseractMRZ`),
but their licenses could not be verified while this project was built. Following the
project's rule of bundling only clearly licensed files, the standard English model is used
with a character whitelist and checksum-guided correction instead.

## Fonts

**No font is bundled.** The OCR benchmark (`packages/ocr/bench`) renders synthetic document
images at run time with fonts already installed on the machine (by default DejaVu Sans Mono,
Liberation Mono and FreeMono), and its output images are not committed. No OCR-B font was
used, because no OCR-B font with a clearly redistributable license was verified. Unit tests
use synthetic canvases drawn in code (blocks, not glyphs).

## Development-only tools

TypeScript, tsup, vitest, fast-check, eslint, prettier, Vite and playwright-core are
development dependencies and are not shipped in the packages.
