Privacy

  • Parsing, check digits, corrections and travel checks run in JavaScript in this tab.
  • Photos are read with an OCR engine (tesseract.js) and an English model that are served with this page. The OCR runs in a worker inside your browser.
  • A Content-Security-Policy blocks every request to other servers: no analytics, no fonts, no CDNs, no uploads. You can check it in your browser's developer tools.
  • Nothing is saved: no cookies, no local storage. Closing the tab forgets everything.
  • Use the "Try a synthetic sample" button to test with invented data.

The MRZ layouts were written from general knowledge of ICAO Doc 9303 and have not yet been verified against the official text, so all formats are marked beta.
